/ 04

Peer to peer
& osservazione

Le 12 ore di osservazione reciproca con il tutor accogliente: protocollo, evidenze, ricadute didattiche.

FASE 1

Progettazione

3 ore

Brainstorming con il tutor, elaborazione del calendario, scelta delle classi e progettazione delle attività per l'osservazione

FASE 2

osservazione

8 ore

Fase di osservazione reciproca: 4 ore in cui il tutee osserva il tutor e 4 ore in cui accade il viceversa. Le lezioni osservate dal tutor sono 2: un'attività di live coding e una di sistemismo Linux

FASE 3

Confronto e debriefing

1 ore

Confronto finale sull'attività di tutoraggio

› obiettivo · interrogare lo stato del sistema (utente, kernel, disco)

# Parte 1 — Navigazione e creazione della struttura dell'archivio

geralt@kaer-morhen:~$ pwd

geralt@kaer-morhen:~$ ls -l

geralt@kaer-morhen:~$ mkdir ~/Desktop/verificaNomeCognome

geralt@kaer-morhen:~$ mkdir ~/Desktop/verificaNomeCognome/Bestiario

geralt@kaer-morhen:~$ mkdir ~/Desktop/verificaNomeCognome/Witcher

geralt@kaer-morhen:~$ touch ~/Desktop/Bestiario.txt ~/Desktop/Pozioni.txt ~/Desktop/Witcher.txt

geralt@kaer-morhen:~$ mv ~/Desktop/Witcher.txt ~/Desktop/Pozioni.txt ~/Desktop/verificaNomeCognome/Witcher/

geralt@kaer-morhen:~$ mv ~/Desktop/Bestiario.txt ~/Desktop/verificaNomeCognome/Bestiario/

geralt@kaer-morhen:~$ ls -lR ~/Desktop/verificaNomeCognome/

› obiettivo · costruire e ispezionare una gerarchia di directory e file

# Parte 2 — Editing con vi + operazioni su file

geralt@kaer-morhen:~$ vi ~/Desktop/verificaNomeCognome/Witcher/Witcher.txt # i · Esc · :wq

geralt@kaer-morhen:~$ vi ~/Desktop/verificaNomeCognome/Witcher/Pozioni.txt

geralt@kaer-morhen:~$ vi ~/Desktop/verificaNomeCognome/Bestiario/Bestiario.txt

geralt@kaer-morhen:~$ cp ~/Desktop/verificaNomeCognome/Witcher/Pozioni.txt \

> ~/Desktop/verificaNomeCognome/Witcher/Pozioni_backup.txt

geralt@kaer-morhen:~$ diff Pozioni.txt Pozioni_backup.txt

geralt@kaer-morhen:~$ rm ~/Desktop/verificaNomeCognome/Witcher/Pozioni.txt

geralt@kaer-morhen:~$ cat ~/Desktop/verificaNomeCognome/Witcher/Witcher.txt

› obiettivo · editing testuale e operazioni essenziali sui file (cp · diff · rm · cat)

# Parte 3 — Utenti, gruppi e permessi

geralt@kaer-morhen:~$ sudo groupadd Witcher

geralt@kaer-morhen:~$ sudo groupadd CacciaSelvaggia

geralt@kaer-morhen:~$ sudo useradd -m Geralt # + sudo passwd Geralt

geralt@kaer-morhen:~$ sudo useradd -m Vesemir

geralt@kaer-morhen:~$ sudo useradd -m Eredin

geralt@kaer-morhen:~$ sudo usermod -aG Witcher Geralt

geralt@kaer-morhen:~$ sudo usermod -aG Witcher Vesemir

geralt@kaer-morhen:~$ sudo usermod -aG CacciaSelvaggia Eredin

geralt@kaer-morhen:~$ sudo cp -r ~/Desktop/verificaNomeCognome/Witcher/. /home/Geralt/

geralt@kaer-morhen:~$ sudo chmod 750 /home/Geralt/ /home/Vesemir/ # rwxr-x---

geralt@kaer-morhen:~$ sudo chmod 700 /home/Eredin/ # rwx------

geralt@kaer-morhen:~$ ls -la /home/Geralt/ && id Geralt
